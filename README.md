# دَرْبَك | Darbak Native GPS 🇮🇶

تطبيق ملاحة تجريبي لأندرويد بـ Kotlin وMapLibre Native (بدون WebView).

## الوظائف الحالية (Native Beta 1.2)
- خريطة Vector بألوان الليل والنهار
- GPS وعدّاد سرعة وسهم الموقع وتتبّع الكاميرا
- الضغط على الخريطة لاختيار الوجهة والبحث داخل العراق
- جلب أسرع طريق وحتى مسارين بديلين من OSRM عندما يتوفران
- عرض المسافة ووقت الوصول التقديري واختيار الطريق المفضل من القائمة
- تسجيلات عراقية فعلية مدمجة من ElevenLabs للانعطاف يميناً ويساراً والوصول: app/src/main/res/raw/*.mp3
- تنبيه صوتي بالقرب من نقطة الانعطاف بواسطة GPS
- نطق أندرويد للأوامر الديناميكية عند توافر صوت عربي على الهاتف
- زر اختبار الصوت وتشغيله وكتمه من القائمة
- حقوق خرائط MapLibre/OpenStreetMap ظاهرة بشكل مناسب

## ملاحظات مهمة
- الطرق تُحسب ببيانات OSRM العامة، ولا تتضمن ازدحاماً مرورياً مباشراً؛ قد لا ترجع الخدمة إلا طريقاً واحداً.
- إرشادات الصوت بالموقع تعتمد على دقة GPS والإنترنت للبحث الأولي عن المسار.
- التسجيلات العراقية للانعطاف والوصول مدمجة وتعمل دون إنترنت، لكن المسافات المتغيرة تعتمد على TextToSpeech إذا توفر صوت عربي.
- التطبيق تجريبي ولم يُختبر على هاتف أندرويد فعلي بعد. لا تعتمد عليه وحده أثناء القيادة.
- ملفات APK من GitHub Actions تستخدم توقيع debug؛ عند اختلاف التوقيع عن نسخة سابقة قد تحتاج إلغاء تثبيتها أولاً.

## بناء APK
افتح [GitHub Actions](https://github.com/alijakarr-collab/Darbak-Native/actions)، واختر أحدث تشغيل ناجح لـ **Build Darbak Native APK**، ثم نزّل ملف **Darbak-Native-debug** من Artifacts. فك ضغطه وثبّت app-debug.apk.

`gradle :app:assembleDebug` باستخدام Java 17 وAndroid SDK 35.
