# دَرْبَك 2.0 — Darbak Native GPS 🇮🇶

مشروع أندرويد تجريبي مبني بـ **Kotlin + MapLibre Native** لتطوير ملاحة مخصصة للعراق.

## الجديد في إصدار 2.0
- **Valhalla routing** مع الرجوع الاحتياطي إلى **OSRM** عند تعذّر حساب المسار؛ كلاهما مصدران تجريبيان عامان حالياً.
- محاولات العثور على مسارات بديلة، مرتبة حسب الزمن التقديري؛ عدد البدائل غير مضمون.
- اختيار المسار عبر **بطاقات سفلية داكنة** تتضمن الزمن والمسافة، ومعاينة كل مسار على الخريطة.
- قياس التقدّم على **مسار الطريق نفسه** باستخدام تقريب موقع GPS على الهندسة، بدلاً من المسافة المستقيمة إلى نقطة الانعطاف.
- إرشادات متدرجة قبل الانعطافات قرب 500م و100م والانعطاف نفسه؛ تعتمد على سرعة التحديث ودقته.
- رصد مغادرة المسار بعد عدة قراءات موثوقة، ومحاولة إعادة التوجيه تلقائياً مع مهلة بين المحاولات.
- **Photon Geocoding** للبحث بعد ضغط المستخدم زر البحث، مع نتيجة اختيار متعددة؛ وNominatim احتياطياً لاستعلام مفرد فقط.
- خيار تفضيل تجنّب الشوارع غير المعبدة عندما تدعمه Valhalla (وقد يُتجاهل عند الرجوع إلى OSRM).
- وضع ليلي ونهاري، البحث المحلي، إعادة توجيهات الصوت، عدّاد سرعة وGPS، وخريطة متجهية بتكبير وتصغير.
- 3 مقاطع صوتية عربية عراقية مدمجة للانعطاف يميناً ويساراً والوصول، مع TextToSpeech للنصوص المتغيرة إذا كان صوت العربية مثبتاً.

## مهم قبل استخدام التطبيق
**إصدار تجريبي، وليس تطبيق ملاحة معتمداً أثناء القيادة.**
- نجاح GitHub Actions يثبت البناء فقط؛ لا يثبت صلاحية الملاحة أو خلوّها من أعطال جهازك.
- المسارات حالياً لا تتضمن حركة مرور لحظية، ولا توجد قاعدة بيانات حوادث أو كاميرات أو إغلاقات مؤكدة.
- Valhalla وOSRM وPhoton خدمات عامة تجريبية ذات حدود استخدام. يُلزم توفير خدمات خاصة أو مزود مدفوع قبل النشر الواسع.
- لا يوجد حتى الآن توجيه بدون إنترنت أو عمل مضمون في الخلفية أثناء إغلاق التطبيق.
- عند غياب محرك TTS عربي، قد تسمع التسجيلات الأساسية فقط دون جميع الأمتار المنطوقة.
- روابط المستودعات التي يعتمد عليها هذا المشروع:
  - https://github.com/maplibre/maplibre-native
  - https://github.com/valhalla/valhalla
  - https://github.com/Project-OSRM/osrm-backend
  - https://github.com/komoot/photon

## تحميل APK من الموبايل
1. افتح https://github.com/alijakarr-collab/Darbak-Native/actions
2. اختر أحدث **Build Darbak Native APK** وتأكد أن النتيجة **Success**.
3. تحت Artifacts نزّل **Darbak-Native-debug**.
4. فكّ ZIP ثم ثبّت **app-debug.apk**. إذا رفض تحديث النسخة القديمة بسبب اختلاف التوقيع، احذف النسخة القديمة أولاً.

## التطوير القادم
- Backend خاص لـValhalla وPhoton مع إعدادات للتوجيه داخل العراق.
- الانتقال إلى SDK متكامل مثل Ferrostar أو MapLibre Navigation SDK بعد إثبات توافقه مع الـAPI والواجهة.
- دعم الملاحة بالخلفية والتنبيهات المتقدمة والاختبارات على الطرق العراقية ثم الخرائط دون إنترنت.
