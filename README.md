# دَرْبَك | Darbak Native GPS 🇮🇶

تطبيق ملاحة تجريبي أصلي لأندرويد باستخدام Kotlin وMapLibre Native (بدون WebView).

## أهم الوظائف
- خريطة vector داكنة ونهارية وتحريك وتكبير بإيماءات اللمس
- تحديد الموقع بإذن المستخدم وسهم / نقطة موقع ومؤشر سرعة GPS
- النقر على الخريطة لتحديد الوجهة وحساب مسار تجريبي
- البحث عن مكان داخل العراق (يتطلب إنترنت)
- واجهة عربية بسيطة مستوحاة من المعاينة السابقة
- حقوق OpenStreetMap / OpenFreeMap ظاهرة في الخريطة

**هذا بناء تجريبي وليس تطبيق ملاحة آمناً للاعتماد عليه أثناء القيادة.** الخرائط والمسارات تعتمد على خدمات خارجية. لا يضم بعد صوت ElevenLabs مدمجاً ولا ازدحاماً مباشراً ولا كاميرات مؤكدة.

## تحميل APK
افتح Actions في GitHub، اختر أحدث Build Darbak Native APK ناجح، ثم نزّل Darbak-Native-debug من Artifacts وفك ZIP للحصول على app-debug.apk.

## Build
`gradle assembleDebug` باستخدام Java 17 وAndroid SDK 35. ملف `.github/workflows/build-apk.yml` يقوم بالبناء السحابي آلياً بعد التحديث.
